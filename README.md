# Evaluación Final Módulo 7

Aplicación desarrollada con Node.js, Express, Sequelize y PostgreSQL para administrar información de países.

## Autor

Magdiel Sánchez Correa

## Funcionalidades

- Listar países con continente, población, PIB 2019 y PIB 2020.
- Paginación de registros (5, 10 o 20).
- Agregar países.
- Eliminar países.
- Manejo de errores.
- Uso de transacciones con COMMIT y ROLLBACK.

## Tecnologías utilizadas

- Node.js
- Express
- Sequelize
- PostgreSQL
- HTML
- CSS
- JavaScript

## Instalación

```bash
npm install
npm run dev
